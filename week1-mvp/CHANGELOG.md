# 更新日志

## 2026-05-23

### 修改

- 通用模型文字解析提示词改为强约束 JSON 输出，并新增中文 `key: value` 文本兜底解析；当中转模型返回“服装结构化属性分析...”这类说明文字时，会尽量转换为项目需要的款式属性结构。
- 侧边栏新增 `产品上架` 入口，位置在 `服饰场景图` 与 `历史记录` 之间。
- 新增 `产品上架` 页面布局：未绑定 Shopify 时显示密钥绑定引导；绑定后显示 Shopify 商品表单、AI 解析结果、字段映射、同步状态与解除绑定确认弹窗。
- `产品上架` 页面已加入前端交互按钮：测试连接、保存绑定、解除绑定、重新解析、应用到表单、保存草稿、同步到 Shopify。
- 新增 Shopify 绑定后端接口：读取绑定、测试连接、保存绑定、解除绑定；保存前会请求 Shopify Admin GraphQL API 验证店铺信息，Access Token 加密存入本地数据库。
- `产品上架` 页面绑定区已接入真实后端接口，填写正确的 `xxx.myshopify.com` 和 `Admin API Access Token` 后可测试并保存绑定。
- `产品上架` 绑定成功后显示本地 Shopify 商品编辑布局，左侧新增大模型完整文字输出窗口，可清理多余空格、乱码和无效字符后自动填入商品标题、描述、分类、标签、SKU、价格、SEO 等字段。
- 新增 Shopify 商品同步接口，点击 `同步到 Shopify` 后会通过 Admin GraphQL API 创建 Shopify 商品，并返回可打开的 Shopify 商品后台链接；库存数量后续接入店铺 Location 后再写入。
- `产品上架` 新增测试密钥：`test.myshopify.com` / `shpat_test_buqiqi`，用于测试绑定后页面切换与同步交互；使用该测试密钥时不会调用 Shopify 官方接口。
